### app-13 — título: `SuperCheck 1.0`

```
Primera versión pública.

## Qué hace
- Listas de compras con la foto, marca y tamaño de cada producto.
- Escáner de código de barras que verifica que llevás el producto correcto.
- Productos propios con foto, favoritos e historial.
- Enviar una copia de la lista por WhatsApp.
- Aviso de versión nueva dentro de la app.

## Importante
Si instalaste una versión de prueba anterior, desinstalala antes: esta usa una llave de firma nueva (se pierden las listas de esas pruebas).

Instalación y límites conocidos: mirá el README.
```
